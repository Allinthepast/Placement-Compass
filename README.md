# Placement Compass — DAEP Year 3

A personal, mobile-friendly placement planner and activity log for 2026–27.

## What is already built in

- 130-day smart placement plan from 4 September 2026 to 31 July 2027.
- Year 3 University contact weeks: w/c 5 October, 23 November and 4 January.
- Year 3 contact day (4 March) and viva support day (6 May).
- Christmas and Easter holiday blocks plus relevant bank holidays.
- A deliberate planning pattern: four placement days per normal week through February, two per week from March–May to protect thesis time, then up to four per week from June until Day 130.
- One study day retained in every ordinary week as a minimum; individual days can be moved in the app.
- Bemrose research timeline: Session Zero + six intervention weeks + evaluation, with the two-week October half-term pause.
- Wednesday/Thursday Bemrose sessions retained during the two affected University contact weeks.
- Research tracked in hours, with a configurable day-equivalent (default 7.5 h/day) and a 30-day maximum.
- Tracked school term/closure information for Bemrose, St Benedict, Firs, Arboretum, Bishop Lonsdale and St John Fisher.
- Activity-log CSV export, JSON backup/restore, print-to-PDF, and termly supervisor review fields.

## Placement start

The Year 3 placement plan begins on **Friday 4 September 2026**, recorded as placement training / CPD and Day 1. The earlier 1–3 September dates are not treated as placement days.

## Use on a phone / install like an app

This repository is designed to be hosted with GitHub Pages. Once Pages is enabled, open the hosted address on your phone and choose **Add to Home Screen / Install app**.

Important: data is currently stored locally in each browser/device. The JSON backup/restore buttons are the safe way to move data between devices. A later version could use a small cloud backend if cross-device live sync is wanted.

## Privacy

No pupil identifiers should be entered. This is deliberately a high-level activity log. The app itself sends no placement data anywhere; external school links only open when clicked.

## Branding

The visual design is University-of-Nottingham-inspired navy with a Derby-style teal accent. It deliberately does not use official logos and is labelled as a personal, unofficial tool.
